# 正则表达式生成

用自然语言描述校验需求，生成正则表达式并附测试用例与说明。

## 何时使用
- 表单校验规则编写
- 日志 / 文本解析模式提取

## 输入 / 输出
- 输入：自然语言校验需求（+ 正反例）
- 输出：正则 + 分组说明 + 测试用例
