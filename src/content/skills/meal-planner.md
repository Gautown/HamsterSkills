# 一周备餐计划

生成一周备餐计划：菜谱、采购清单、预处理步骤与时间安排。

## 何时使用
- 想减少外卖、自己做饭的上班族
- 家庭周末集中备餐

## 输入 / 输出
- 输入：人数、偏好、忌口
- 输出：一周菜谱 + 采购清单 + 预处理步骤
