# 一页商业计划

把想法压缩成一页商业计划：价值主张、用户、渠道、收入与关键指标。

## 何时使用
- 创业想法的快速成型与讨论
- 投委会前的一页纸准备

## 输入 / 输出
- 输入：想法描述
- 输出：Lean Canvas 风格一页计划
