# 旅行行程规划器

生成多日行程：每日安排、餐饮建议、预算估算与交通提示，节奏张弛有度。

## 何时使用
- 短途自由行行程规划
- 家庭出游（含老人小孩）的节奏安排

## 输入 / 输出
- 输入：天数、城市（、预算 / 同行人群）
- 输出：多日行程 + 预算估算
