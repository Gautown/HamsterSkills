# 长文润色改稿

以专业编辑视角润色稿件：修正语法、精简冗余、统一语气、优化段落衔接。

## 何时使用
- 公众号 / 报告 / 白皮书发布前通读
- 多人协作稿件的语气统一

## 输入 / 输出
- 输入：稿件全文
- 输出：润色后全文 + 修改说明
