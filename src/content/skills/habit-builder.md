# 习惯养成方案

为目标习惯设计 21 天养成方案：触发器、最小行动、断档处理与奖励机制。

## 何时使用
- 健身 / 阅读 / 早起等自我提升目标
- 反复失败后需要外部结构

## 输入 / 输出
- 输入：习惯 + 当前状态
- 输出：21 天方案（触发 / 最小行动 / 断档 / 奖励）
