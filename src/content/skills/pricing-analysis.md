# 定价策略分析

分析现状定价问题，输出 3 种可选策略（含锚定 / 分层 / 免费增值）与预估影响。

## 何时使用
- 调价、上新套餐前的策略讨论
- 免费增值层设计

## 输入 / 输出
- 输入：当前定价 + 转化 / 流失数据
- 输出：诊断 + 3 策略 + 灰度方案
