# Logo 概念草案

基于品牌关键词输出 3 套 Logo 概念方向，含图形语言、配色与字体建议。

## 何时使用
- 新品牌启动的 Logo 方向探索
- 设计提案前的概念发散

## 输入 / 输出
- 输入：品牌名、行业、关键词
- 输出：3 套概念方向（图形 / 配色 / 字体 / 理念）
