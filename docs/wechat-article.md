## 正文

你装了 Claude Code、Cursor 或者 opencode 之后，是不是也经历过这个阶段：

工具本身很强，但用着用着发现——**真正决定效率的，是它会不会"某一门手艺"**：写周报、清洗数据、做竞品调研、审代码、排错……

这些"手艺"，在 AI 工具的世界里叫 **Agent Skills**（技能）。它们不写在工具里，而是散落在 GitHub 的几千个仓库中。

问题来了：**去哪儿找？怎么挑？怎么装？**

我干脆自己造了个地方——

# 🐹 仓鼠AI技能库

**skill.gautown.top**

一句话介绍：**把全网公开的 AI Agent Skills 收集、分类、打分，做成一个能搜索、能复制、能一键安装的站点。** 目前收录：

- 技能：**8000+**（每天还在涨）
- 标签：**1200+**
- 语言：**中文 / 繁体 / English / 한국어 / Bahasa Melayu**
- 页面：**29000+**（是的，一个技能 × 五种语言就是一叠页面）

## 它到底能干什么？

**① 按用途找，不用按仓库名猜**

首页按 10 个分类铺开：办公、开发、绘图、写作、数据……每个技能卡片都能看到用途、评分和来源。搜"周报"、"数据清洗"、"爬虫"这种生活化的词，一样能搜到——因为搜的是"这个技能能干什么"，而不是仓库名。

**② 复制提示词，立刻能用**

每个技能详情页都准备了现成的提示词（Prompt）：复制 → 粘贴到你的 AI 工具里 → 开始干活。哪怕你用的工具不支持"技能"这个概念，Prompt 也能用。

**③ 一键安装到 AI 工具**

支持 `npx skills add` 安装通道的技能，详情页直接给命令：复制一行，回车，技能就装进你的 Claude Code / Cursor / opencode 里了。

**④ 不认识要什么？问它**

站内有个"技能库助手"：直接说"我想找能帮我做竞品分析的技能"，它会在全部技能里检索后给你推荐。

## 它是怎么自动跑起来的？（技术篇）

作为独立开发者，我最满意的不是功能，而是**这个站点基本不需要我管**。

**每天早上自动"进货"**

一条流水线在 GitHub Actions 上定时运行：

1. 从 GitHub 抓取最新技能仓库；
2. 交给 AI 做分类、评分、质量筛查（垃圾项目直接淘汰）；
3. 构建 29000+ 页面；
4. 五个站点并行发布到 Cloudflare Workers。

我能看到的最新技能，你也能看到。

**为什么是五个站点？**

不是我想复杂，而是 Cloudflare 免费版单个 Worker 有 2 万个静态资产的上限。2.9 万页放不下，就按语言切成五份：主站管根路径，英文、繁体、韩文、马来文各占一个路径段，共享同一套资源文件。访客无论点进哪个语言，加载的都是自己那一份，快。

**2.9 万个页面，搜索怎么做到秒回？**

不可能给 2.9 万页每页塞一份完整索引。做法是：

- 首页只内联前 150 张卡片，保证首屏够快；
- 完整索引压缩成一份 JSON，用户输入关键词时按需加载 + 缓存；
- 检索用"子串 + IDF"双路合并：既保证不漏（搜"test"能全量召回），又保证相关性（常用词权重自动降低）。

**静态站也能"在线改站"**

这是我觉得最有趣的一块：站点是纯静态的，但我在后台管理系统里改站名、改 Logo、改首页文案、改"关于/联系/隐私政策"页的内容，**都不用重新部署**。

原理不复杂：后台把配置写进 Cloudflare KV，页面加载时有一个极小的脚本去拉配置、覆盖页面上的对应位置。静态的骨架 + 动态的灵魂。后台的账号密码用 PBKDF2 哈希存储，也没有明文。

**外观与广告**

UI 参考了 Stripe 的视觉语言（靛蓝主色、渐变、克制的留白）；广告方面接入了 Ezoic，并按合规要求写了完整的隐私政策页——站点要长期活下去，这部分不能省。
